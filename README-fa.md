# mackolik-mcp 🇹🇷

mcp-name: io.github.mohammad-abbasi-sh/mackolik-mcp

سرور MCP غیررسمی و **فقط-خواندنی** برای mackolik.com، برنامهٔ شمارهٔ ۱ نتایج زندهٔ ورزشی ترکیه (~۳۸ میلیون نصب) — نتایج زنده، نتایج نهایی، برنامهٔ بازی‌ها، جدول لیگ‌ها و جزئیات مسابقه برای فوتبال (و بسکتبال) در سراسر جهان، با اولویت لیگ‌های ترکیه.

> ساخته‌شده توسط محمد عباسی در چارچوب «کارخانهٔ MCP ترکیه» (خط تولید به سبک سپهر). وابسته به mackolik.com نیست. فقط برای Mackolik ساخته شده — هرگز Sahadan (همان مالک، همان دادهٔ زیرین).

## برای ایجنت‌های هوش مصنوعی

به پیکربندی MCP client خود اضافه کنید (stdio):

```json
{
  "mcpServers": {
    "mackolik": {
      "command": "uvx",
      "args": ["mackolik-mcp"]
    }
  }
}
```

یا به‌صورت محلی اجرا کنید: `python -m mackolik_mcp.server` (نیازمند `mcp<2` و `curl-cffi`).

## ابزارها

| ابزار | توضیح |
|------|-------|
| `mackolik_live_scores` | بازی‌های در حال برگزاری — فیلتر اختیاری زیررشتهٔ `league` (مثلاً «Süper Lig»، «Premier Lig»)، `limit` ۱ تا ۵۰؛ دقیقه، نتیجه، نیمهٔ اول، کارت‌های قرمز، ضرایب ۱/X/۲ |
| `mackolik_results` | بازی‌های تمام‌شدهٔ یک تاریخ (پیش‌فرض امروز) — `date` به‌صورت YYYY-MM-DD یا DD/MM/YYYY، فیلتر `league`، `limit` ۱ تا ۵۰ |
| `mackolik_fixtures` | بازی‌های پیش‌روی یک تاریخ (پیش‌فرض امروز) — همان پارامترهای results |
| `mackolik_standings` | جدول لیگ — `league`: Tur (سوپر لیگ ترکیه)، Eng (لیگ برتر)، Esp (لالیگا)، Ita (سری A)، Ger (بوندس‌لیگا)؛ رتبه، تیم، بازی، امتیاز، تفاضل گل |
| `mackolik_match_detail` | جزئیات کامل یک مسابقه با `match_id` (از ابزارهای دیگر) + `date` اختیاری (فید روزانه است، پس برای بازی گذشته تاریخ لازم است) |

## نحوهٔ کار

mackolik.com به arsiv.mackolik.com هدایت می‌شود (جلوِ Akamai، بدون دیوار ربات). دادهٔ زنده از فید JSON خود سایت می‌آید: `vd.mackolik.com/livedata` — جاوااسکریپت سایت آن را با `?group=0` (کل امروز، ۸۳۶ مسابقه در ۲۰۲۶-۱۱-۰۷) یا `?date=DD/MM/YYYY` (۱٬۳۷۰ مسابقه برای ۰۷/۱۱/۲۰۲۶) فرامی‌خواند؛ بدون ورود و کلید API. ردیف‌های مسابقه آرایه‌هایی‌اند که بر اساس فایل `livescore-go.js` خود سایت رمزگشایی شده‌اند: شناسه، تیم‌ها، کد وضعیت، متن وضعیت، نتیجه، جزئیات نیمهٔ اول/کارت قرمز، ساعت شروع، ضرایب ۱/X/۲ (فقط نمایشی)، تاریخ و گروه لیگ (کشور، لیگ، فصل). کدهای وضعیت: ۰/۱۲ = شروع‌نشده، ۱/۳/۵ = زنده (عدد دقیقه در status_text — سایت علامت `'` را هنگام نمایش اضافه می‌کند)، ۱۴/۱۵/۱۷ = وقت‌های بسکتبال، ۲۰ = وقت اضافه («UZ»)، ۴/۱۳ با «MS» = تمام‌شده (Maç Sonu). مسابقهٔ زنده/تمام‌شده با فیلد نتیجهٔ خالی ۰-۰ است (هنوز گلی زده نشده). جدول‌ها از هندلر ویجت خود سایت می‌آیند (`Home/StandingHandler.aspx?league=Tur|Eng|Esp|Ita|Ger`). انتقال با جعل TLS کروم انجام می‌شود (`curl-cffi`، `chrome120`)؛ درخواست‌ها با فاصلهٔ ‎~۰٫۸ ثانیه فرستاده می‌شوند؛ همه‌چیز فقط-خواندنی است. توجه: «Süper Lig» نام لیگ در یونان، سوئیس، صربستان، اسلواکی، هند و اندونزی هم هست — فیلد `country` را بررسی کنید.

## نصب

```bash
uvx mackolik-mcp        # اجرای مستقیم (نیازمند uv)
# یا
pip install mackolik-mcp
mackolik-mcp    # سرور MCP را روی stdio راه می‌اندازد
```

## تست‌ها

```bash
python -m venv .venv && .venv/bin/pip install -e .
.venv/bin/python -m unittest discover -s tests -v
```

تست‌های آفلاین روی داده‌های ضبط‌شده اجرا می‌شوند (پاسخ‌های واقعی فید از ۲۰۲۶-۱۱-۰۷)؛ تست‌های زنده به mackolik.com وصل می‌شوند. در زمان ساخت ۲۶ از ۲۶ سبز بود (۱۴ آفلاین + ۱۲ زنده) به‌همراه یک تست دود MCP روی stdio (۳۴ مسابقهٔ زنده، صدرنشین سوپر لیگ گالاتاسرای با ۲۵ امتیاز).

## نقشهٔ راه

- گل‌زنان / رویدادهای مسابقه (صفحهٔ جزئیات برای بازی‌های تمام‌شده آن‌ها را دارد)
- نتایج زندهٔ بسکتبال به‌عنوان فیلتر درجه‌یک (فیلد sport همین حالا تجزیه می‌شود)
- بازی‌های روبه‌رو / فرم تیم از صفحه‌های تیم
